# ไทย (th) (th)

## App Name
Revak: เวลาละหมาดและกิบลัต            ← (26/30)


## Subtitle
อะซาน อัลกุรอาน และซิกิร            ← (24/30)


## Keywords
ละหมาด,ทิศ,เข็มทิศ,รอมฎอน,ถือศีลอด,ละศีลอด,ซะกาต,กอฎอ,ฮิจเราะห์,ปฏิทิน,อัสมาอุ,ฮุสนา,ดุอา,มัสยิด            ← (96/100)


## Promotional Text
ไม่มีโฆษณา ไม่เก็บข้อมูล อะซานเต็มเสียง อัลกุรอานออฟไลน์ กิบลัตที่ซื่อตรง เครื่องนับซิกิร กอฎอและซะกาต สิ่งจำเป็นฟรีเสมอ            ← (120/170)


## Description
ไม่มีโฆษณา ไม่เก็บข้อมูล แอปที่คุณตรวจสอบเวลาได้ด้วยตัวเอง

Revak ไม่เคยนำเวลาละหมาด ทิศกิบลัต การแจ้งเตือนอะซาน อัลกุรอาน หรือเครื่องนับซิกิร ไปไว้หลังการสมัครสมาชิกหรือโฆษณา การอิบาดะฮ์เองยังคงฟรีเสมอ

— เวลาคำนวณบนเครื่องของคุณเอง
ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องมีสัญญาณ เลือกวิธีคำนวณที่คุณเชื่อถือ ปรับแต่ละเวลาได้ละเอียดถึงนาที และดูในแผงความโปร่งใสว่าตัวเลขแต่ละตัวมาจากไหน

— เรื่องอัสรี เราถามคุณ
ทัศนะส่วนใหญ่กับทัศนะฮะนะฟีอาจทำให้เวลาอัสรีต่างกันเกือบหนึ่งชั่วโมง Revak แสดงทั้งสองเวลาตอนตั้งค่าและปล่อยให้คุณเลือกเอง

— อะซานจริง เต็มความยาว
ด้วย AlarmKit ใน iOS 26 อะซานดังครบทั้งบท แม้อยู่ในโหมดเงียบหรือเปิดโฟกัสอยู่ เสียงอะซานคุณเลือกเอง

— กิบลัตที่ซื่อตรง
ถ้าเข็มทิศยังไม่ได้ปรับเทียบ เราจะบอกตามตรงแทนที่จะชี้ผิดทาง มีการตรวจสอบด้วยดวงอาทิตย์รวมอยู่ด้วย

— อัลกุรอาน แบบออฟไลน์
ข้อความภาษาอาหรับครบถ้วนพร้อมคำแปล ฝังอยู่ในแอป ไม่ต้องต่ออินเทอร์เน็ต

— ซิกิร 99 พระนาม กอฎอ ซะกาต
เครื่องนับซิกิรที่ให้สัมผัสเหมือนลูกประคำจริง พร้อมเป้าหมายสำเร็จรูป 33/99/100 พระนามทั้ง 99 ฟรีทั้งหมด เช่นเดียวกับการติดตามละหมาดกอฎอและเครื่องคำนวณซะกาต

— รอมฎอนและปฏิทิน
นับถอยหลังสู่การละศีลอดและสิ้นสุดสะฮูร ปฏิทินฮิจเราะห์ และการแจ้งเตือนคืนอันประเสริฐ

— วิดเจ็ต Live Activity และ Apple Watch
เวลาละหมาดถัดไปบนหน้าจอล็อกและบน Apple Watch

— REVAK PLUS
สิ่งจำเป็นยังคงฟรีตลอดไป Plus เพิ่มวิดเจ็ตขั้นสูง ธีม เสียงอะซานของคุณเอง ประวัติซิกิรไม่จำกัด ชุดพระนาม กิบลัตแบบ AR หลายเมือง และการซิงก์ผ่าน iCloud ทดลองฟรีเจ็ดวัน ยกเลิกได้ด้วยการแตะครั้งเดียวในการตั้งค่า            ← (1463/4000)
